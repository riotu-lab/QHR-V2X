# Research Paper Integration Guide

This document provides guidance for integrating this codebase with your research paper's experiments section.

### ✅ Repository Readiness

- [x] **Complete algorithm implementations** (QHR-V2X, baselines)

- [x] **Statistical analysis tools** for validation

### ✅ Paper Integration Points

1. **Abstract/Introduction**: Reference the repository for reproducibility

3. **Experiments Section**: Provide reproduction commands
4. **Results Section**: Reference generated figures and analysis
5. **Conclusion**: Acknowledge open-source contribution

## 📝 Suggested Paper Text

### For Abstract/Introduction

> "To ensure reproducibility and facilitate future research, we provide a complete open-source implementation of QHR-V2X along with all experimental data and analysis scripts. The implementation is available at: https://github.com/riotu-lab/QHR-V2X"

### For Methodology Section

> "Our implementation follows the experimental design described in Section X, with grid-based V2X simulation environments ranging from 10×10 to 100×100 nodes. We use fixed random seeds (seed=12345) to ensure reproducible results across all experiments. The complete implementation, including quantum circuit designs and statistical analysis tools, is publicly available in our repository."

### For Experiments Section

> "All experimental results can be reproduced using the provided scripts. To run the complete experiment suite:

```bash
git clone git@github.com:riotu-lab/QHR-V2X.git
cd QHR-V2X
poetry install
python experiments/scripts/reproduce_paper_results.py
```

> "Statistical analysis and visualization can be generated using:

```bash
python experiments/analysis/analyze_results.py
```

> "This generates publication-ready figures and comprehensive statistical reports, including ANOVA tests and pairwise comparisons with Bonferroni correction."

### For Results Section

> "Performance comparison plots and statistical analysis are automatically generated by our experimental framework. All figures in this paper were created using the `analyze_results.py` script, ensuring consistency and reproducibility. Raw data and analysis scripts are available in the repository's `experiments/` directory."

## 🚀 Quick Start for Reviewers

### For Peer Reviewers

```bash
# 1. Clone and setup
git clone git@github.com:riotu-lab/QHR-V2X.git
cd QHR-V2X
poetry install

# 2. Reproduce key results
python experiments/scripts/reproduce_paper_results.py --algorithms qhr_v2x,dijkstra,astar

# 3. Generate analysis
python experiments/analysis/analyze_results.py

# 4. View results
open experiments/analysis/results/
```

### For Researchers

```bash
# 1. Test QHR-V2X implementation
python main.py compare qhr_v2x qhr_v2x_classical

# 2. Run custom experiments
python main.py selective qhr_v2x dijkstra astar

# 3. Full benchmark suite
python main.py benchmark
```

## 🔧 Customization for Your Paper

### Algorithm Selection

If you want to test specific algorithms mentioned in your paper:

```bash
# Edit the algorithms list in reproduce_paper_results.py
python experiments/scripts/reproduce_paper_results.py --algorithms your_algorithm_list
```

### Grid Size Customization

To modify experimental parameters:

```python
# Edit tests/test_pathfinding_all.py
sizes = [10, 20, 30, 40, 50]  # Your custom grid sizes
density = 0.3  # Your custom obstacle density
```

### Visualization Customization

For paper-specific figures:

```python
# Edit experiments/analysis/analyze_results.py
plt.rcParams.update({
    'font.size': 12,        # Your preferred font size
    'figure.dpi': 300,      # Your preferred resolution
    'savefig.bbox': 'tight' # Your preferred layout
})
```
